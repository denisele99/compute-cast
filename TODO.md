# Hackathon checklist

## First
- [ ] Run both services and submit the default workload.
- [ ] Push to GitHub and commit npm's generated lockfile.
- [ ] Agree on supported workload and API fields with teammate.

## Core product
- [ ] Collect a representative benchmark and record configuration.
- [ ] Add GPU catalog with dated source links and region/currency pricing.
- [ ] Add model/optimizer/precision fields and a justified memory model.
- [ ] Display estimate ranges and calibration provenance.
- [ ] Add required sponsor runtime integration server-side.
- [ ] Add meaningful calculation/API checks as the estimator grows.

## Finish
- [ ] Deploy frontend and backend; configure /api routing.
- [ ] Test small, large and over-memory workloads.
- [ ] Record a 2-minute demo and take backup screenshots.
- [ ] Verify all submission links and sponsor requirements.
